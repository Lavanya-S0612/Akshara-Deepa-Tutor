# Akshara Deepa Tutor

AI-based educational Android application for SSLC students with quizzes, progress tracking, and strength analysis.

## Features
- Subject-wise quizzes
- Progress tracking
- Strength analysis
- Interactive UI

## Technologies Used
- Kotlin
- Android Studio
- Jetpack Compose

## Installation Steps
1. Clone repository
2. Open in Android Studio
3. Sync Gradle
4. Run the application
