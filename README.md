# Akshara Deepa Tutor

Akshara Deepa Tutor is an AI-based educational Android application developed for SSLC students.

## Features
- Subject-wise quizzes
- Progress tracking
- Strength analysis
- Interactive UI

## Technologies Used
- Kotlin
- Android Studio
- Jetpack Compose
  
- ## Installation Steps
1. Clone repository
2. Open in Android Studio
3. Sync Gradle
4. Run the application

## Future Enhancements
- Firebase integration
- AI recommendations
- Multi-language support
